# TileProto

macOS 菜单栏自动窗口平铺工具：窗口一打开就自动排好，不用手动拖来拖去。单文件 Swift 实现，`swiftc` 直编，不需要 Xcode 工程。

## 功能

- **四种布局**：Grid、Columns、Rows、Side。一块屏实际能放下几格看可见区域：Grid 恒为 4；MacBook 级屏幕 Columns 3、Rows 2、Side 3，更宽（≥1800pt）Columns 到 4，更高（≥1100pt）Rows 到 3，宽高都过线 Side 才到 4。竖屏按行堆。超过容量的数量按钮是灰的
- **自动平铺**：开窗、关窗立即重排，邻窗滑进空出来的位置，不留空格；关掉自动平铺后新窗口居中浮动，已有磁贴保持不动，重开立即重排
- **堆叠**：窗口数超过磁贴数时，新窗口堆进活动磁贴最上面；刚好满格时按住 ⌃⌘ 把一扇窗拖到另一格上，也会并进去并收掉原来的格子。磁贴上方有橙色握把（当前窗口那一截更长），点一下或按 ⌃⌥` 切换
- **主窗口尺寸**：Half / 60% / Two-thirds（Grid 两格是等分、四格是田字，不受这项影响）；间距 4 / 8 / 16 pt，窗口之间和屏幕边缘同一间距，单窗全屏不留边。拖两格之间的整条缝，整列或整行一起变宽，比例会被记住
- **Focus**：活动窗口以短弹簧放大到屏幕工作区，其余窗口留在原处被盖住；再按一次缩回进入前记下的 frame
- **Clean Space**：其余窗口滑出所有屏幕之外，活动窗口弹簧到屏幕中央，桌面铺深灰，Dock 和菜单栏仍在
- **No peek**：非活动窗口罩一层 50% 暗色，开和关都是淡入淡出
- **悬停快捷条**：指针在任意磁贴上沿停留约 0.2 秒，弹出深色条：堆叠时有 ‹ › 和每个窗口的芯片，以及 Primary / Focus / Float。Hover focus（指针停住就激活）默认关
- **鼠标拖放**：按住 ⌘ 拖到另一磁贴交换两扇窗口；按住 ⌃⌘ 拖到某磁贴加入堆叠；普通拖动松手后弹簧弹回原磁贴，并提示要按 ⌘ 才能交换
- **Tab View**：按住 ⌥ 再按 ⇥，按屏显示磁贴缩略图；⇥ / ⇧⇥ 换窗口，方向键换到相邻磁贴，松开 ⌥ 切过去，Esc 取消
- **动效**：布局、交换、Focus、弹回都是大约 0.5 秒的短弹簧，带一点过冲，下一次布局会从飞行中的位置改道。拖分隔线是手跟着走，不走弹簧
- **多显示器**：每块屏独立平铺；支持 Spaces 切换后重排；Stage Manager 开启时自动暂停
- **开机启动**、**单窗口全屏**、**对话框与浮动窗永不平铺**、**按应用排除平铺**

## 安装

要求：macOS（在 macOS 27、Swift 6.4 下开发），需要授予**辅助功能**和 **Input Monitoring** 权限（没有这两项，窗口移动和全局快捷键都不会生效）。

```bash
git clone https://github.com/longyunBegin/TileProto.git
cd TileProto
./build.sh
open TileProto.app
```

启动后菜单栏出现 ▦ 图标，点开就是控制面板。

> 未签名说明：本应用没有 Apple 开发者签名。macOS 会把每次换过的二进制当成新应用，所以**每次重新构建后都要重做一次授权**：系统设置 → 隐私与安全性 → 辅助功能，删掉所有 TileProto 条目后重新添加 `TileProto.app`，再到 Input Monitoring 里勾选 TileProto。菜单栏图标从 ▦! 变成 ▦ 即授权成功。

## 使用

面板里可以改：自动平铺开关、布局、每屏磁贴数（1–4，超这块屏容量的按钮是灰的）、主窗口尺寸、间距、Retile、Borders、Hover focus、Focus、恢复浮动窗口、No peek mode、Clean Space、Tile 前台应用。

常用操作：

- 改布局、改磁贴数、堆叠产生、普通拖动松手、Retile、进入 Focus、开关 No peek 时，屏幕中部偏下会出现黑色提示条，大约 2.5 秒后消失。Focus 的提示会留着，直到退出
- 拖分隔线改尺寸：缝本身就是手柄（没有单独的蓝点），拖动实时跟随，松手保持
- 浮动窗口：悬停条点 Float，或 ⌃⌥F；面板点“恢复浮动窗口”可把浮动窗口重新排进磁贴
- 屏幕满时新窗口默认堆进活动磁贴；也可在设置里改成居中浮动，直到有空位时自动归位
- 设置窗口共 5 页：General、Layout、Mouse、Keyboard、Apps（不平铺的应用列表）。TileProto 在前台时 ⌘, 打开设置

## 隐私

- 不读取窗口内容，不保存窗口标题，不联网
- 日志只记应用名与计数，存在 `~/tileproto/tileproto.log`
- 不做购买、许可证、激活

## 从源码构建

```bash
./build.sh
```

只做三件事：`swiftc -O` 编译 `main.swift`，拷入 `Info.plist`，有 `TileProto.icns` 时拷入 Resources（没有也能跑，只是没自定义图标）。

应用图标是程序化绘制的，`drawIcon.swift` 会生成 1024×1024 的 PNG：

```bash
swift drawIcon.swift        # 生成 /tmp/TileProtoIcon.png
```

再用 `sips` 生成各尺寸、`iconutil -c icns` 打包成 `TileProto.icns` 放到仓库根目录即可。

## 已知限制

- 未签名，每次换二进制都要重授权（见安装一节）
- 多显示器部分在单屏环境开发，仍需第二块屏验证
- 悬停条、堆叠识别靠进程与标题匹配，同应用同标题的两个窗口可能认错
- 最小尺寸学习需要“此前已够大、落点后仍缩不到”的应用才能触发，覆盖面有限
- 窗口圆角、红绿灯和壁纸由系统绘制。平铺改的是 frame，加上自己的握把、暗色层、提示和 Tab View
- 有的应用会丢掉连续的尺寸设置，弹簧是尽力而为；手动堆叠关系只活在这一次运行里
