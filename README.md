# TileProto

macOS 菜单栏自动窗口平铺：窗口一打开就排进格子，关掉就让旁边的窗口补上。单文件 Swift，用 `swiftc` 直接编译，不需要 Xcode 工程。

操作只在鼠标和菜单栏面板上。

## 它做什么

1. **摆放**。自动平铺开着时，新窗口得到一块格子，不留重叠。
2. **补位**。窗口关闭或离开格子后，旁边的窗口补上，不留空格。
3. **形状**。一种自适应布局，间距固定 8 pt。数量上限 1–4，和当前窗口数取更小的那个：1 格铺满工作区、不留边；2 格左右分；3 格三列；4 格田字。最小尺寸偏大的窗口会多分到一块：两格和田字最多大约七成，三列最多大约一半，旁边的格子不会被压成一条缝。
4. **溢出**。窗口比格子多时，堆进当前这块格子，大家共用同一个矩形。格子比已学最小尺寸还窄、但整块屏放得下时，并进面积最大的那一格，而不是飘在旁边。只有某一维已知的最小尺寸比整块屏还大，才按当前尺寸居中浮动。边长记成 0 的那一维当作还不知道，不当成高度或宽度 0。格子上方有橙色握把，最前面那一截更长，点一下轮换。指针在格子上沿停留约 0.2 秒会出现悬停条，上面有每个窗口的芯片和 ‹ ›。
5. **用鼠标改**。拖两块格子之间的整条缝，两侧一起变，中间留着 8 pt，不会叠到一起。缝上有一条细握把。比例按这块屏和格子数记住。按住 ⌘ 再拖：窗口缩小一点跟着指针走，目标格子略向内收，松手后两扇都滑到最终位置，不过冲。按住 ⌃⌘ 拖到某块格子上，并进那一叠，空出来的格子收掉。普通拖动不会重排：松手后弹回上次落点，并提示要按住 ⌘。
6. **悬停条**。普通格子上是 Primary、Focus、Float，文字旁边各有一个小图标。堆叠芯片上是应用图标。没有快捷键键帽。Primary 把这扇窗口和第 0 格最上面的那扇对调，已经在第 0 格顶部时按钮是灰的。Focus 把当前窗口铺满这块屏的工作区，其余窗口留在下面；再把指针放到屏幕上沿，点悬停条上的 Focus，按进入前记下的位置缩回去。Float 按窗口当前尺寸居中，其余窗口立刻补位；浮动窗口的悬停条只有一个 Tile，点一下按当前布局重新排回去。面板上的「恢复浮动」会把所有浮动窗口收回来。只有一个按钮的条子按内容宽度收缩，不会空出半截。
7. **面板**。自动平铺、这一屏的窗口、数量 1–4（每颗按钮画出这一档会排成的样子）、重新平铺、恢复浮动、开机启动、当前前台应用是否平铺。数量按钮是图，不是空框。重新平铺和恢复浮动是带图标的方块。开机启动和前台应用各占一行，左边图标、右边开关。活动格子有一圈描边，其余格子盖一层约 50% 的暗色，这两项固定开着。没有键盘设置页，也没有只能靠按键才能用的功能。

每块屏各自平铺，数量上限是全局的。切换 Space 之后重排。Stage Manager 开着时暂停，窗口保持原样。对话框、工作表和面板不平铺。关掉自动平铺后，已经排好的窗口不动，此后新开的窗口居中浮动；再打开会立刻重排。

某个应用不想被平铺：它在最前面时，用面板上的 Tile 开关关掉。名单写在 `~/tileproto/excluded.txt`。

学到的最小尺寸按应用名记在本机。接近整屏、几乎没缩小的尺寸不会记成最小值。某一维已经能缩进更小的格子时，这一维的旧下限会丢掉。两维都 ≤0 的记录启动时丢弃；只有一维有值的留下，另一维当未知。比当前屏幕大约 85% 还大的记录会先收一档。

平铺、Focus 和普通弹回大约 0.5 秒，带一点过冲。⌘ 交换大约 0.34 秒，落到终点为止，不过冲。拖分隔线是 1:1，不走弹簧。提示大约 2.5 秒。

## 权限

只需要**辅助功能**（系统设置 → 隐私与安全性 → 辅助功能），用来移动和缩放窗口。

未签名说明：本应用没有 Apple 开发者签名。macOS 会把每次换过的二进制当成新应用，所以每次重新构建后都要重做一次授权：系统设置 → 隐私与安全性 → 辅助功能，删掉旧的 TileProto 条目，再添加当前的 `TileProto.app`。菜单栏图标从 ▦! 变成 ▦ 即授权成功。

## 安装

```bash
git clone https://github.com/longyunBegin/TileProto.git
cd TileProto
./build.sh
open TileProto.app
```

启动后菜单栏出现 ▦，点开就是控制面板。

## 从源码构建

```bash
./build.sh
```

脚本做三件事：`swiftc -O` 编译 `main.swift`（链接 AppKit 和 ApplicationServices），拷入 `Info.plist`，有 `TileProto.icns` 时拷入 Resources。没有图标也能运行。

应用图标是程序化绘制的：

```bash
swift drawIcon.swift
```

会生成 `/tmp/TileProtoIcon.png`。再用 `sips` 做出各尺寸，`iconutil -c icns` 打成 `TileProto.icns`，放到仓库根目录。

## 隐私

- 不读取窗口内容，不保存窗口标题，不联网
- 日志只记应用名和计数，写在 `~/tileproto/tileproto.log`
- 不平铺的应用包名写在 `~/tileproto/excluded.txt`
- 学到的最小尺寸按应用名记在本机偏好里，不上传
- 不做购买、许可证或云同步

## 已知限制

- 未签名，每次换二进制都要重新授权辅助功能
- 多显示器按每块屏独立平铺；第二块屏上的鼠标命中还需要实机看
- 能拿到系统窗口号时，悬停条、堆叠和 Focus 按窗口号认窗口。拿不到时退回进程加标题，同一个应用里两扇标题相同的窗口仍可能认错；再撞车时会加序号，避免 Focus 因为重复键直接崩溃
- 窗口圆角、红绿灯和壁纸由系统绘制。平铺改的是 frame，再加上握把、暗色层、描边和提示
- 有的应用会丢掉连续的尺寸设置，弹簧是尽力而为。手动堆叠关系只在这一次运行里
- ⌘ 拖交换依赖鼠标 tap；面板提示 ⌘ 拖暂不可用时应用会在短时间内自动重试，仍失败请重开应用或检查 Input Monitoring 授权
