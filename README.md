# TileProto

macOS 菜单栏自动窗口平铺：窗口一打开就排进格子，关掉就让旁边的窗口补上。单文件 Swift，用 `swiftc` 直接编译，不需要 Xcode 工程。

操作只在鼠标和菜单栏面板上。

## 它做什么

1. **摆放**。自动平铺开着时，新窗口得到一块格子，不留重叠。
2. **补位**。窗口关闭或离开格子后，旁边的窗口补上，不留空格。
3. **形状**。四种布局，数量上限 1–4，和当前窗口数取更小的那个。Grid：1 格铺满工作区（仍留当前间距）；2 格左右分；3 格是左边一块大的、右边两块小的；4 格是左列对半、右列两格。Columns 是竖条，Rows 是横条，Side 是左侧主格、右侧把其余窗口上下叠起来。主格份额可选 1/2、60%、2/3。份额停在 1/2 时，Columns 和 Rows 按份数等分，三列仍是三等分；Grid 四格在 60% / 2/3 时只拉宽左列，高度仍对半。间距 0–24 pt（2 pt 一档），默认 8，窗缝和屏幕边缘同一套。格子比大约 160×100 还小时，面板里更高的数量会变灰，并写明这一屏装不下。
4. **溢出**。窗口比格子多时：默认堆进当前这块格子，大家共用同一个矩形；也可在面板改成「满格时居中浮动」，新窗口先浮着，有空位再归位。已知最小尺寸比格子大过 4 pt 时，先并进一个装得下的格子；手动堆在一起的窗口整组跟着走。并到只剩一整屏仍装不下，才按最小尺寸在可视区中央浮动，并从平铺里拿掉。边长记成 0 的那一维当作还不知道。写入辅助功能的帧不会超出格子；弹簧过程中探出的中间帧也会收回去。格子上方有橙色标记，点一下轮换。指针在格子上沿停留约 0.15 秒会出现悬停条。
5. **用鼠标改**。拖两块格子之间的缝，两侧一起变，中间留着当前间距，不会叠到一起。缝上有一条细握把。拖过之后可以用 Reset sizes 清掉这些比例，回到布局自己的份额。按住 Command 再拖：窗口缩小一点跟着指针走，目标格子略向内收，松手后两扇都滑到最终位置，不过冲。再按住 Option 拖到某块格子上，并进那一叠（高亮写 Add to stack），空出来的格子收掉；拖动中途按住或松开 Option，以松手时的组合为准。普通拖动不会重排：松手后弹回上次落点，并提示要按住 ⌘。面板和悬停条里不放键帽符号。
6. **悬停条**。上面一行是堆叠芯片（‹、应用名、›），芯片多的时候可以横向滚动。下面一行始终是三列：Primary、Focus、Float，图标在上、文字在下。Primary 在可以交换时保持清楚可点；已经在第 0 格顶部时点击不会交换，文字仍然可读。Primary 把这扇窗口换进大格。Focus 把当前窗口铺满这块屏的工作区；再点一次 Focus，按进入前记下的位置缩回去。Float 放到可视区中央，宽约 60%、高约 75%，不低于已知最小尺寸，四周留在可视区 16 pt 以内；其余窗口立刻补位。浮动窗口的悬停条只有一个 Tile，点一下按当前布局重新排回去。面板上的「恢复浮动」会把所有浮动窗口收回来。
7. **面板**。自动平铺、这一屏的窗口、布局族、数量 1–4、主格份额、间距、满格时堆叠/浮动、Reset sizes、重新平铺、恢复浮动、Tab view、No peek、暗色强度、Borders、Hover focus、Clean Space、开机启动、当前前台应用是否平铺。No peek 开着时，其余格子盖一层暗色，强度大约 10%–90%，默认约 28%；关掉就恢复原样。Borders 开着时，活动格子外侧的缝里有一条细描边。Hover focus 开着时，指针在格子上停留约 0.15 秒会把该窗口提到前面。Clean Space 只留当前窗口居中，四周用帘子挡住，其余窗口最小化；关掉后按进入前的位置放回来。Tab view 列出应用图标和名字，点一下切到那个窗口，不截取窗口画面。没有单独的设置窗口，也没有键盘设置页。

每块屏各自平铺，数量上限是全局的。切换 Space 之后重排。Stage Manager 开着时暂停，窗口保持原样。对话框、工作表和面板不平铺。关掉自动平铺后，已经排好的窗口不动，此后新开的窗口居中浮动；再打开会立刻重排。

某个应用不想被平铺：它在最前面时，用面板上的 Tile 开关关掉。名单写在 `~/tileproto/excluded.txt`。

学到的最小尺寸按应用名记在本机。接近整屏、几乎没缩小的尺寸不会记成最小值。某一维已经能缩进更小的格子时，这一维的旧下限会丢掉。两维都 ≤0 的记录启动时丢弃；只有一维有值的留下，另一维当未知。比当前屏幕大约 85% 还大的记录会先收一档。

平铺、Focus 和普通弹回大约 0.5 秒，带一点过冲。Command 交换大约 0.34 秒，落到终点为止，不过冲。拖分隔线是 1:1，不走弹簧。提示大约 2.5 秒。

## 权限

只需要**辅助功能**（系统设置 → 隐私与安全性 → 辅助功能），用来移动和缩放窗口。

未签名说明：本应用没有 Apple 开发者签名。macOS 会把每次换过的二进制当成新应用，所以每次重新构建后都要重做一次授权：系统设置 → 隐私与安全性 → 辅助功能，删掉旧的 TileProto 条目，再添加当前的 `TileProto.app`。菜单栏图标从 ▦! 变成 ▦ 即授权成功。

## 安装

```bash
git clone https://github.com/longyunBegin/TileProto.git
cd TileProto
./build.sh
open TileProto.app
```

启动后菜单栏出现 ▦，点开就是控制面板。

## 从源码构建

```bash
./build.sh
```

脚本做三件事：`swiftc -O` 编译 `main.swift`（链接 AppKit 和 ApplicationServices），拷入 `Info.plist`，有 `TileProto.icns` 时拷入 Resources。没有图标也能运行。

应用图标是程序化绘制的：

```bash
swift drawIcon.swift
```

会生成 `/tmp/TileProtoIcon.png`。再用 `sips` 做出各尺寸，`iconutil -c icns` 打成 `TileProto.icns`，放到仓库根目录。

## 隐私

- 不读取窗口内容，不保存窗口标题，不联网
- 日志只记应用名和计数，写在 `~/tileproto/tileproto.log`
- 不平铺的应用包名写在 `~/tileproto/excluded.txt`
- 学到的最小尺寸按应用名记在本机偏好里，不上传
- 不做购买、许可证或云同步

## 已知限制

- 未签名，每次换二进制都要重新授权辅助功能
- 多显示器按每块屏独立平铺；第二块屏上的鼠标命中还需要实机看
- 能拿到系统窗口号时，悬停条、堆叠和 Focus 按窗口号认窗口。拿不到时退回进程加标题，同一个应用里两扇标题相同的窗口仍可能认错；再撞车时会加序号，避免 Focus 因为重复键直接崩溃
- 窗口圆角、红绿灯和壁纸由系统绘制。平铺改的是 frame，再加上握把、暗色层、描边和提示
- 有的应用会丢掉连续的尺寸设置，弹簧是尽力而为。手动堆叠关系只在这一次运行里
- 拖交换依赖鼠标 tap；面板提示拖交换暂不可用时应用会在短时间内自动重试，仍失败请重开应用或检查 Input Monitoring 授权
- Tab view 只列出应用图标和名字。No peek 是一层暗色，没有模糊。没有独立的设置窗口和键盘页
- 布局几何可以在 Mac 上用 `swiftc -D TILEPROTO_SELFTEST main.swift -framework AppKit -framework ApplicationServices` 跑一遍，通过后进程会自己退出
