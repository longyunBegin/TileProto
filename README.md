# TileProto

macOS 菜单栏自动窗口平铺：窗口一打开就排进磁贴，关掉就让旁边的窗口补上。单文件 Swift，用 `swiftc` 直接编译，不需要 Xcode 工程。

操作只在鼠标和菜单栏面板上。

## 它做什么

1. **摆放**。自动平铺开着时，新窗口得到一块磁贴，不留重叠。
2. **补位**。窗口关闭或离开磁贴后，旁边的窗口补上，不留空格。
3. **形状**。四种布局：Grid、Columns、Rows、Side。每块屏的数量是 1–4，再和这块屏可见区域能放下的数量取更小的那个。放不下的数量按钮是灰的，点了会提示。
4. **溢出**。窗口比磁贴多时，堆进当前这块磁贴，大家共用同一个矩形。磁贴上方有橙色握把，最前面那一截更长，点一下轮换。指针在磁贴上沿停留约 0.2 秒会出现悬停条，上面有每个窗口的芯片和 ‹ ›。设置里可以改成先居中浮动，直到出现空位再归位。默认是堆叠。
5. **用鼠标改**。拖两块磁贴之间的整条缝，宽度跟手变化，比例按这块屏、当前布局和磁贴数记住。按住 ⌘ 把窗口拖到另一块磁贴上，松手交换。按住 ⌃⌘ 拖到某块磁贴上，并进那一叠，空出来的格子收掉。普通拖动不会重排：松手后弹簧弹回，并提示要按住 ⌘。
6. **注意力**。Focus 把当前窗口弹簧铺满工作区，其余窗口留在下面；再点一次 Focus，按进入前记下的位置缩回去。减弱其他给非活动窗口盖一层约 50% 的暗色，开和关都是淡入淡出，菜单栏和 Dock 不动。演示把其他窗口移出所有屏幕，当前窗口留在深色桌面中央，菜单栏和 Dock 仍在；再点一次恢复。
7. **面板是全部开关**。自动平铺、布局、数量、主窗口份额、间距、重新平铺、边框、悬停激活、Focus、减弱其他、演示、当前前台应用平铺与否、设置。没有只能靠按键才能用的功能。

主窗口份额是 Half / 60% / Two-thirds，用在有一块主格的布局上。Grid 两格是等分，四格是田字，不看这项。间距 4 / 8 / 16 pt，窗口之间和屏幕边缘用同一个数。只有一块磁贴时铺满工作区，不留边。

悬停条上还有 Primary、Focus、Float。悬停激活（指针停住就激活窗口）默认关。

布局、交换、Focus 和弹回大约 0.5 秒，带一点过冲；下一次布局会从飞行中的位置改道。拖分隔线是 1:1，不走弹簧。布局、数量、堆叠、普通拖动、减弱其他的提示大约 2.5 秒。Focus 和演示的提示留到退出。

每块屏各自平铺。切换 Space 之后重排。Stage Manager 开着时暂停，窗口保持原样。对话框、工作表和面板不平铺。关掉自动平铺后，已经排好的窗口不动，此后新开的窗口居中浮动；再打开会立刻重排。

某个应用不想被平铺：它在最前面时，用面板上的 Tile 开关关掉。设置里的 Apps 页可以查看和移除。

## 权限

只需要**辅助功能**（系统设置 → 隐私与安全性 → 辅助功能），用来移动和缩放窗口。

未签名说明：本应用没有 Apple 开发者签名。macOS 会把每次换过的二进制当成新应用，所以每次重新构建后都要重做一次授权：系统设置 → 隐私与安全性 → 辅助功能，删掉旧的 TileProto 条目，再添加当前的 `TileProto.app`。菜单栏图标从 ▦! 变成 ▦ 即授权成功。

## 安装

```bash
git clone https://github.com/longyunBegin/TileProto.git
cd TileProto
./build.sh
open TileProto.app
```

启动后菜单栏出现 ▦，点开就是控制面板。设置窗口有四页：General、Layout、Mouse、Apps。

## 从源码构建

```bash
./build.sh
```

脚本做三件事：`swiftc -O` 编译 `main.swift`（链接 AppKit 和 ApplicationServices），拷入 `Info.plist`，有 `TileProto.icns` 时拷入 Resources。没有图标也能运行。

应用图标是程序化绘制的：

```bash
swift drawIcon.swift
```

会生成 `/tmp/TileProtoIcon.png`。再用 `sips` 做出各尺寸，`iconutil -c icns` 打成 `TileProto.icns`，放到仓库根目录。

## 隐私

- 不读取窗口内容，不保存窗口标题，不联网
- 日志只记应用名和计数，写在 `~/tileproto/tileproto.log`
- 不平铺的应用包名写在 `~/tileproto/excluded.txt`
- 不做购买、许可证或云同步

## 已知限制

- 未签名，每次换二进制都要重新授权辅助功能
- 多显示器按每块屏独立平铺；这部分在单屏环境写的，第二块屏上的命中还需要实机看
- 悬停条和堆叠靠进程与标题匹配，同一个应用里两扇标题相同的窗口可能认错
- 窗口缩不到磁贴尺寸时改为居中浮动，不另做最小尺寸的管理界面
- 窗口圆角、红绿灯和壁纸由系统绘制。平铺改的是 frame，再加上握把、暗色层和提示
- 有的应用会丢掉连续的尺寸设置，弹簧是尽力而为。手动堆叠关系只在这一次运行里
